# 🧪 Project Amadeus — AI Desktop Study Assistant

> *"People's feelings are memories that transcend time."* — Kurisu Makise

**Project Amadeus** is a lightweight desktop companion powered by Python, PyQt6, and Google Gemini AI. Inspired by the **Amadeus System** from *Steins;Gate*, this application brings **Kurisu Makise** right to the bottom-right corner of your screen to help you study, solve complex problems, and stay focused.

---

## ✨ Features

* **Always-on-Top Transparent HUD:** A frameless, non-intrusive desktop overlay that sits neatly in the corner of your screen without cluttering your taskbar.
* **Interactive Subtitle Bubble:** Clean, readable dialogue window positioned right next to Kurisu for instant explanations and study tips.
* **AI Study Mentor (Powered by Gemini):** Ask questions about programming, math, science, or any academic subject—and get accurate answers delivered with Kurisu's signature tsundere personality.
* **Voice & Text Input *(In Progress)*:** Communicate naturally via keyboard or microphone.
* **Dynamic Expressions *(Planned)*:** Sprite changes reacting to your questions and study progress.

---

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **GUI Framework:** PyQt6
* **AI Engine:** Google GenAI SDK (Gemini)
